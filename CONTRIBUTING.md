# Contributing

Thanks for your interest in this repo!

## Quick start

```bash
npm install
npm run dev          # or appropriate dev command
```

## Before opening a PR

1. Run the full check chain (typecheck + lint + build).
2. Update `CHANGELOG.md` if user-facing.
3. PR description: include motivation, approach, screenshots.

## Commit message format

```
<type>(<scope>): <description>

[optional body]

[closes #N, #M]
```

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`, `ci`.
